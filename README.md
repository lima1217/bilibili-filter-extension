# B站视频过滤器

按关键词、UP主、时长、播放量过滤 B站视频；在页面上悬停封面即可一键屏蔽，并可隐藏广告、直播等推荐。

## 功能

**在页面上直接操作**
- 鼠标移到视频封面，左上角出现屏蔽按钮：屏蔽 UP主 / 不想看这个视频 / 按关键词屏蔽
- 每次操作都有「撤销」提示，误点不怕
- 左下角角标显示本页过滤数量；点击进入**预览模式**，被过滤的视频会半透明显示并标注原因，可以直接取消对应规则

**规则**
- 关键词：匹配标题，不区分大小写；支持 `/正则/`；逗号或换行分隔可批量添加
- UP主：支持名称、UID、空间链接；按 UID 精确匹配，UP主改名后仍然有效
- 单个视频：按 BV 号屏蔽
- 时长、播放量：设定上下限（播放量支持输入「1.5万」）
- 内容类型：广告推广（默认开启）、直播、番剧/影视/课堂楼层
- 白名单 UP主：不受关键词、时长、播放量等规则影响
- 生效页面：首页、搜索、视频页推荐、其他页面可分别开关

**其他**
- 修改立即生效，并同步到所有已打开的 B站标签页，无需刷新
- 每条规则显示累计命中次数，方便清理无用规则
- 配置可导出 / 导入 JSON；自动迁移 v1 的旧设置
- 跟随系统深色模式

## 安装

1. 下载或克隆本仓库
2. 打开 `chrome://extensions/`，开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择项目文件夹

## 项目结构

```
├── manifest.json
├── src/
│   ├── shared/
│   │   ├── core.js       # 设置结构、v1 迁移、规则匹配（纯函数，可在 Node 中测试）
│   │   └── store.js      # chrome.storage 读写与变更监听
│   ├── content/
│   │   ├── extract.js    # 各类页面卡片的识别与字段提取
│   │   ├── main.js       # 过滤引擎、悬停屏蔽菜单、撤销提示、角标与预览
│   │   └── content.css   # 隐藏 / 预览样式
│   └── popup/            # 弹出窗口
├── tests/core.test.js
└── icons/
```

适配新的页面结构时，通常只需要在 `src/content/extract.js` 的 `ADAPTERS` 中增加一项。
