# B站视频过滤器 Chrome 扩展

一个简洁高效的 Chrome 扩展，帮助你过滤 B站首页不想看的视频内容。

![Extension Screenshot](./screenshots/preview.png)

## ✨ 功能特性

- **关键词屏蔽** - 添加关键词，标题包含关键词的视频会被自动隐藏
- **UP主屏蔽** - 添加UP主名称，该UP主的所有视频都会被隐藏
- **时长过滤** - 设置最短/最长时长，过滤过短或过长的视频
- **播放量过滤** - 设置最低/最高播放量，过滤低质量或蹭热度内容

## 📦 安装方法

### 开发者模式安装

1. 下载或克隆本仓库
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`
3. 开启右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择项目文件夹

*即将上线*

## 🚀 使用方法

1. 点击浏览器工具栏中的扩展图标
2. 在对应标签页中添加要屏蔽的内容：
   - **关键词**：输入要屏蔽的关键词，按回车添加
   - **UP主**：输入要屏蔽的UP主名称
   - **时长**：设置时长范围，或使用快速预设
   - **播放量**：设置播放量范围
3. 刷新 B站页面，设置立即生效

## 🛠️ 技术栈

- **Manifest V3** - 最新的 Chrome 扩展规范
- **Vanilla JavaScript** - 无框架依赖，轻量高效
- **CSS Variables** - 可定制的设计系统
- **Chrome Storage API** - 设置持久化存储
